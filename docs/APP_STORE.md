## 説明（4000文字まで）

```
「前回いつだっけ？」「今日何回目だっけ？」
TapStamp は、ボタンを押した日時をそのまま残すだけのシンプルな記録アプリです。

起動して、画面中央の丸いボタンをタップ。それだけで今の日時が記録されます。入力も設定もいりません。思い立ったその瞬間に、片手で、1秒で記録できます。

■ こんなことに
・薬を飲んだ時刻
・トイレやくしゃみの回数
・タバコやコーヒーの本数
・水分補給
・シーツや歯ブラシを替えた日
・散髪に行った日
ほかにも「いつ」「何回」を残しておきたいことなら何でも。

■ とりあえず記録
最初のページは、ラベルなしの「とりあえず記録」。何の記録か決めていなくても、まず押して残せます。

■ ラベルで分けて記録
「薬」「トイレ」などのラベルを作ると、記録画面を左右にスワイプして切り替えられます。ラベルごとに色が変わるので、今どれを記録しているかひと目で分かります。
はじめて起動したときは、よく使うラベルをテンプレートから選べます（スキップもできます）。

■ 押し間違えても大丈夫
記録すると画面下に「記録しました 14:32｜取り消す」と表示されます。押し間違えたら、その場で取り消せます。あとから時刻を直したり、記録を削除したりもできます。

■ あとで見返せる「ふりかえり」
ラベルごとに、見たいものを2種類から選べます。

【回数・頻度】
・前回からの経過時間
・今日の回数
・直近7日の日別グラフ
・曜日と時間帯ごとの傾向（直近4週間）

【間隔】
・前回から何日経ったか
・平均の間隔、最短と最長

■ データは端末の中だけ
アカウント登録はありません。記録は端末の中にだけ保存され、外部のサーバーに送られることはありません。広告もトラッキングもありません。

※本アプリは記録を残して見返すためのメモアプリです。記録の内容をもとに判断や助言を行うものではありません。
```

## App Review に関する情報 → メモ

```
ログインやアカウント登録は不要です。
初回起動時にラベルのテンプレート選択画面が表示されます（「あとで設定」でスキップできます）。
「記録」タブの中央の丸いボタンをタップすると、その時点の日時が端末内に記録されます。左右にスワイプするとラベルを切り替えられます。
「ふりかえり」タブで、記録した回数・間隔・グラフを確認できます。
データはすべて端末内（SwiftData）に保存され、ネットワーク通信は行いません。
```

サインイン情報は「サインインが必要」のチェックを外します。
